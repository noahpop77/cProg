# Current Micro-Projects

### termAnimation

This micro projects purpose is to play around with `drawing and specifcally moving` things to a terminal screen.

It utilizes the terminals alt mode and and raw mode to allow me to have full control over how pixels are drawn to the screen. This means that I have to handle a lot of the things that terminals do automatically like screen cleanup and so on.
